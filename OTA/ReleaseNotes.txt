2. LOGICA DI SICUREZZA E LICENZE CORPORATE
-------------------------------------------------------------------------------
 Il software adotta protocolli di sicurezza per la protezione del workflow:

 > LICENZA: Sistema "Node-Locked" vincolato univocamente al ComputerID.
 > ARCHIVIAZIONE: File di configurazione e licenza segregati in %LOCALAPPDATA%
   per garantire la resilienza del sistema in caso di spostamento dell'eseguibile.
 > PRIVACY: Validazione locale tramite hashing MD5. Nessun dato sensibile o
   struttura file viene trasmessa all'esterno della rete aziendale.

5. MANUALE OPERATIVO DETTAGLIATO (USER GUIDE V3.1.5)
-------------------------------------------------------------------------------
 FASE A: PREPARAZIONE E SINCRONIZZAZIONE
 1. All'avvio, VENUS interroga il NAS nel percorso configurato.
 2. Selezionare l'anno fiscale dal menu a tendina (es. 2026).
 3. Il sistema scansiona l'archivio e propone automaticamente il primo numero 
    disponibile nel formato [AA-NN] (es. 26-04).

 FASE B: INSERIMENTO DATI (LOGICA SMART-INPUT)
 1. Individuare il campo centrale dove appare "26-XX NOME CLIENTE" (in grigio).
 2. FARE CLICK sul testo: La scritta "NOME CLIENTE" sparirà, lasciando il 
    numero di commessa e uno spazio già pronti (es. "26-04 ").
 3. DIGITARE il nome del cliente o della commessa. 
    NOTA: Se si cancella accidentalmente il numero, è possibile riscriverlo 
    o cliccare fuori dal campo e rientrare per ripristinare il suggerimento.
 4. REGOLE NOMI: Evitare caratteri speciali come \ / : * ? " < > |

 FASE C: PERSONALIZZAZIONE STRUTTURA
 1. Nel pannello a scorrimento centrale (Scrollbar Oro), selezionare le 
    sottocartelle necessarie per il progetto specifico.
 2. Cartelle Tecniche: Vengono create nella radice della commessa.
 3. Cartelle Amministrazione: Vengono raggruppate nella sottodirectory 
    "Amministrazione", ereditando i permessi protetti dal Modello.

 FASE D: GENERAZIONE E DEPLOYMENT
 1. Premere il pulsante blu "CREA COMMESSA".
 2. Il sistema esegue tre operazioni in background:
    - Creazione della directory principale sul NAS.
    - Clonazione speculare dei file contenuti nella cartella _MODELLO_.
    - Rimozione automatica degli attributi di sistema errati.
 3. Al termine (1-2 secondi), si aprirà automaticamente una finestra di 
    Esplora Risorse posizionata all'interno della nuova commessa creata.

 FASE E: RISOLUZIONE PROBLEMI RAPIDA
 - Messaggio "Inserire nome cliente": Hai premuto Crea senza scrivere nulla 
   dopo il numero di commessa.
 - Icona Ingranaggio: Da utilizzare solo se il server cambia indirizzo IP 
   o se viene spostata la cartella "_MODELLO_".
 - Icona Info (i): Utilizzare per copiare l'ID PC da inviare all'assistenza.
